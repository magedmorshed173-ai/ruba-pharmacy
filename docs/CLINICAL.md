## 2) البنية العلمية — ثلاثة أعماق فوق القاعدة المنقحة

```
الطبقة 3 — المتلازمات التراكمية (syndrome-panels.ts)
           فحص القائمة كاملة: QT / سيروتونين / نزيف / CNS / سكر / كلوية
        ↑
الطبقة 2 — التنبؤ الميكانيكي (cyp450.ts)
           خريطة إنزيمات ⇒ تدخلات متوقعة حتى بلا ثنائية منقّحة
        ↑
الطبقة 1 — القاعدة المنقحة (100+ ثنائية، DrugInteraction)
           شديدة التوثيق: شدة + آلية + أثر + إدارة + أدلة + مصدر
```

**قواعد الأولوية الثابتة** (مصممة كي لا يتناقض المحرك مع نفسه):
1. المنقّح الموثق يعلو على أي تنبؤ — التنبؤ لا يظهر أصلاً لثنائية منقّحة.
2. التنبيه الأشد يعلو داخل التصنيف (SEVERITY_RANK ثابت مُختبَر).
3. **التنبؤ لا يحجب الصرف أبداً** — الحجب حكر على: ممنوع منقّح + تعارض حساسية + بوابة حمل/عمر حاجبة + سجل وطني محظور. التنبؤ طبقة مساندة معلَّمة «نظري/مرجّح» — نفس فلسفة Medi-Span في فصل «التنبيه» عن «الحجب».

## 3) مصادر التصنيف والمراجع

- **Stockley's Drug Interactions** — مرجع الآليات والإدارة.
- **Lexicomp** — تصنيف الشدة وخطط المراقبة.
- **تحذيرات FDA الرسمية** — حدود الجرعات والمنع المطلق (سيمفاستاتين×أملوديبين 20مغ، مثال).
- **خريطة FDA CYP450 + PharmGKB** — بناء الملفات الإنزيمية.
- **AGS Beers Criteria 2023** — كبار السن.
- **Cockcroft & Gault (1976)** — التصفية الكلوية.
- تقييد الإسقاط: كل نص سريري مكتوب بالعربية الطبية المهنية — قابل للعرض على الصيدلي مباشرة دون ترجمة.

## 4) حدود المنهجية (شفافية علمية كاملة)

- قاعدة التنبؤ الإنزيمي تغطي ~55 مادة عالية التردد — ليست شاملة، والتوسع مستمر.
- التنبؤ الميكانيكي يفترض مثبطاً/محفّزاً «قوياً» دون تدرج قوة التثبيط (مستقبل: strong/moderate/weak).
- المتلازمات التراكمية تعتمد مطابقة نصية جزئية للمواد — القيود موثقة في الكود.
- كل ذلك لا يغني عن قرار الصيدلي — النظام «يدعم القرار» ولا «يستبدله»، وهذا مذكور في الواجهات.
