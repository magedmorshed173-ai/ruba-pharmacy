— المزايا —

كل ما تحتاجه الصيدلية في منصة واحدة

مبني على أنماط الأنظمة الرائدة (Odoo، ERPNext، GNU Health) مع إغلاق الثغرات التي وجدناها فيها لصالح الصيدلية العربية.

🛒

نقطة بيع ذكية

سلة تفاعلية ببحث فوري بالاسم أو الباركود، خصومات، دفع نقدي/شبكة، فاتورة رقمية بمقاس 80مم، ومنع تكرار البيع تقنياً عبر Idempotency.

⚠️

بوابة السلامة الدوائية

26 تداخلاً موثقاً بعد نمط Lexicomp/Stockley: أربع درجات شدة، الآلية الدوائية، الأثر السريري، خطة الإدارة، والمصدر العلمي — و«ممنوع سريرياً» يحجب البيع مع تجاوز مسؤول مسجّل للصيدلي (v3.5).

🧊

دفعات LOT وصرف FEFO

كل تشغيلة بصلاحية وتكلفة مستقلة، والأقرب انتهاءً يُصرف آلياً، والمنتهي محجوب حتى لو أظهر الرصيد توفره — بلا استثناءات.

v3.2
🚚

موردون وأوامر شراء

سجل موردين كامل وأوامر شراء ببنود متعددة، والاستلام ذري: يولّد دفعات LOT بالتكلفة الفعلية ويحدّث الرصيد وسجل الحركات في معاملة واحدة.

v3.3
📈

ربحية بتكلفة فعلية

لقطة تكلفة FEFO لحظة البيع لكل بند — هامش ربح حقيقي لكل صنف وفترة، لا تقديرات ولا متوسطات مضللة.

v3.4
📷

باركود بالكاميرا + وضع الاتصال

مسح الباركود بكاميرا الجهاز عبر BarcodeDetector، مؤشر حالة اتصال حي، وحجب البيع عند انقطاع الشبكة لحماية البيانات.

🧬

مطابقة الحساسية والعلاج المكرر (v3.5)

حساسية «بنسلين» تحجب أموكسيسيلين وأوجمنتين تلقائياً عبر عائلات دوائية علمية، وأدوية الفئة العلاجية نفسها (ATC) تُرصد كمكررة داخل السلة.

📊

تقارير وتنبؤ ذكي

لوحة KPIs حية، مبيعات ومقارنات، تنبؤ إعادة الطلب بمعدل الاستهلاك ومهلة التوريد، وتصدير CSV لكل تقرير.

🔐

أمان مؤسسي

JWT في كوكي httpOnly، bcrypt، أدوار مركزية (مدير/صيدلي/فني)، تحديد معدل دخول، سجل تدقيق لكل محاولة، والنقود بالهللات — صفر أخطاء تقريب.

📱

PWA + Docker جاهزان

قابل للتثبيت على الجوال كتطبيق مستقل، قابل للتغليف TWA نحو Google Play، وصورة إنتاج Docker ب healthcheck ومستخدم غير جذر.

— رحلة التطوير —

ستة إصدارات من الإطلاق إلى النضج

تطور حقيقي موثق في CHANGELOG — كل إصدار أُغلق بمراجعة واختبارات وبناء إنتاجي ناجح عبر CI.

v3.0الإطلاق الكامل

منصة Next.js 16 بواجهة عربية RTL: نقطة بيع، مخزون، مرضى، تقارير، إشعارات، مستخدمون، نسخ احتياطي — مع إغلاق ثغرات النسخة القديمة.

v3.1دفعات + FEFO + أمان

تتبع تشغيلات LOT بصلاحية مستقلة، صرف FEFO آلي، تحديد معدل الدخول، وضع ليلي، فاتورة 80مم، وأول 19 اختبار وحدوي.

v3.2سلسلة التوريد

موردون وأوامر شراء باستلام ذري يولّد دفعات بالتكلفة الفعلية ويدمج التشغيلات المكررة بأمان.

v3.3أرباح حقيقية وتدقيق

لقطات تكلفة عند البيع وتقارير هامش ربح فعلي، مع سجل تدقيق كامل لكل محاولات تسجيل الدخول ولوحة أمان للمدير.

v3.4الجوال أولاً

مسح باركود بالكاميرا، مؤشر اتصال وحجب البيع دون شبكة — استعداداً لطابور أوفلاين كامل وتغليف TWA.

v3.5العمق السريري

بوابة سلامة دوائية في مسار البيع، 26 تداخلاً موثقاً بآلية وإدارة ومصدر، مطابقة حساسية متقاطعة، كشف العلاج المكرر، رؤوس أمان حديثة، و114 فحصاً آلياً بين وحدوي وحي.
